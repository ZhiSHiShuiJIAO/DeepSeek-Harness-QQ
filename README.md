# 大肥鱼QQ

让 DeepSeek Harness 住进你的 QQ：图形界面、十个人设、语音、表情包、唱歌、群聊 @、提醒待办、余额查询。

> **⚠ 免责声明**：本程序依赖第三方协议端（NapCat）登录 QQ，违反腾讯《QQ 软件许可及服务协议》，**存在封号风险**。请使用小号，后果自负。
>
> **仅供个人使用**：禁止商用、禁止改名后二次分发。详见 [LICENSE](LICENSE)。

## 一、它是什么

```
你的 QQ ←→ NapCat（第三方 QQ 协议端）←→ 本程序 ←→ DeepSeek Harness（模型 + 工具）
```

本程序负责：收消息、白名单、排队、调模型、发语音/表情/图片、记小本子、定时主动找你、到点提醒你。

| 需要 | 说明 |
|---|---|

| **DeepSeek Harness 桌面版** | 本程序靠它的 `dsh headless` 跑模型，必须已安装 |

## ⚠ 风险提示（务必先看）

**用 NapCat 这类第三方协议端登录 QQ，违反腾讯官方《QQ 软件许可及服务协议》，有封号风险。**

- **强烈建议用一个小号**，不要用主号，更不要用有好友/群/游戏资产的号
- 封号可能是临时的，也可能是永久的，且**申诉基本无效**
- 同一 IP 挂多个号、频繁掉线重登、短时间大量发消息，都会提高被风控的概率
- 本项目只提供客户端，**不对任何封号后果负责**

如果只是想试试，用闲置小号；如果要长期用，走官方 QQ 机器人平台。

## 三、三步启动

### 1. 填信息

双击 `启动整合包.bat`，在「连接」卡片里填：

- **你的 QQ 号**：只有这个号能指挥机器人（必填，白名单）
- **DeepSeek Key**：`sk-...` 开头（必填）
- **机器人 QQ 号**：登录 NapCat 的那个号，登录成功后会自动填

### 2. 选人设

「人设」下拉框里挑一个，右边显示一句话摘要，点「预览」看全文。十个人设：

| 人设 | 性别 | 什么味道 |
|---|---|---|
| 大肥鱼 | — | 成精的胖鱼，梗一箩筐，抽象但关键时刻靠谱 |
| 女儿（阿糖） | 女 | 黏人爱撒娇，一天找你两三次 |
| 元气学妹 | 女 | 话多、爱笑、主动分享日常 |
| 傲娇青梅 | 女 | 从小一起长大，嘴硬心软的教科书 |
| 三无学姐 | 女 | 话极少，一句顶十句 |
| 猫娘 | 女 | 懒、馋、好奇，关键时刻靠得住 |
| 高冷学长 | 男 | 不废话，直接给判断 |
| 阳光学弟 | 男 | 热心、直来直去、有点憨 |
| 腹黑弟弟 | 男 | 表面乖，一句软刀子让你自己心虚 |
| 毒舌损友 | — | 先损你三句，再帮你办事 |

每个人设末尾都带同一套规则：**像真人说话**（接具体那句、允许停顿、说一句分一条）、**玩梗尺度**（三五句一个、不解释梗、他认真时不玩）、**认真模式**（谈钱谈健康时立刻收）、**底线**（不编事实、不打听隐私）。

想自己写：往 `personas\` 扔一个 `.txt`，重开程序就能选到。

### 3. 点「启动」

状态区会显示：

```

```

## 四、装 NapCat + 扫码（只需一次）

1. 点界面里的「**一键下载 NapCat**」——直接下载官方 `NapCat.Shell.Windows.OneKey.zip`（约 0.9 MB 的安装器）
2. 解压后运行 `NapCatInstaller.exe`，它会把 QQ 和 NapCat 一起装好，装完进 `NapCat.XXXX.Shell` 目录
3. 把这个目录挪到 `D:\NapCat` 或整合包旁边的 `napcat` 文件夹，让界面能自动找到
4. 回到整合包，点「**启动 NapCat**」——自动提权（UAC 点「是」），QQ 登录窗弹出
5. 左上的方框会显示二维码，**用手机 QQ 扫**（建议小号）
6. 状态依次变成：`等待扫码` → `已扫码，快在手机上点确认登录` → `已登录 · 你的小号 QQ`
7. 登录后打开 NapCat WebUI（`http://127.0.0.1:6099`），加两条网络配置：

| 类型 | 配置 |
|---|---|
| HTTP 服务器 | `127.0.0.1:3000`，token 留空 |
| HTTP 上报 | `http://127.0.0.1:8787/onebot`，格式 `array` |

> 整合包不会自动装 NapCat——它是第三方程序，装不装由你决定。
>
> 网络不好下载不动时，可以用官方 Gitee 镜像 `https://gitee.com/anydev/NapCatQQ`，或者给链接加 GitHub 加速站前缀。

## 五、功能清单

| 功能 | 怎么用 |
|---|---|
| 聊天 | 直接发消息 |
| 语音 | 她说「[语音]…[/语音]」时自动合成；`/voice off` 关闭 |
| 表情包 | 她按情绪和关键词发图；`/sticker` 看库存 |
| 唱歌 | `/唱 小星星`（歌单在 `core\sandbox\sing\songs\`） |
| 看图 | 你发图片，她能看懂（存到 `core\sandbox\inbox\`） |
| 小本子 | `/记忆` 看它记了什么；聊久了自动轮换会话但小本子保留 |
| 余额 | 直接问「还有多少余额」；界面上也有「查余额」按钮 |
| **提醒待办** | 「提醒我明天八点开会」→ 到点主动发消息；`/提醒` 查看，`/删提醒 1` 删除 |
| **群聊 @** | 群里 @ 她才回（默认关闭，见第七节） |
| 主动找你 | `proactive.enabled` 打开后，空闲 20–55 分钟随机开一次口 |
| 检查更新 | 界面上「检查更新」按钮，比对远端 `version.json` |
| 命令 | `/help` 看全部 |

### 功能开关

「功能」卡片里四个勾选框，关掉哪个就不触发哪个：

```
☑ 语音 [edge▾]   ☑ 表情包   ☑ 唱歌   ☑ 余额   ☑ 风控
```

**风控**勾选框鼠标悬停 0.5 秒会弹出说明卡，解释每一条的具体数值和改法。

## 六、目录说明

```
qq-kit\
├─ 启动整合包.bat        双击它
├─ app.py                图形界面
├─ config.example.json   配置模板（app 据此生成 core\config.json）
├─ personas\             十个人设，可自己加
├─ assets\songs\         歌单源文件
└─ core\
   ├─ bridge.py          主程序（收消息、排队、调用模型、风控）
   ├─ tts.py             语音合成（edge / gpt-sovits / mimo）
   ├─ reminders.py       提醒 / 待办（独立线程 + JSON 持久化）
   ├─ _vendor\           edge-tts 及其依赖（包内自带，不用 pip）
   ├─ config.json        真正的配置，第一次保存后生成
   ├─ persona.txt        当前生效的人设
   ├─ reminders.json     提醒数据（重启不丢）
   ├─ logs\              运行日志，按天切分：bridge-2026-10-28.log
   ├─ sandbox\           模型的工作目录（它只能动这里）
   └─ tools\card2persona.py  角色卡转换器
```

**安全边界**：模型的 `cwd` 被锁在 `core\sandbox\`，它碰不到 `bridge.py`、`config.json`，也碰不到你的其他文件。

## 七、群聊怎么开

**默认是关的**，需要两处一起改（`core\config.json`）：

```json
"allowed_groups": [123456789],
"group": {
  "enabled": true,
  "require_at": true,
  "min_gap_ms": 4000,
  "max_per_hour": 20
}
```

- 只有 @ 到机器人才回复，`@全体成员` 不算
- 同一个群两条之间至少隔 4 秒，每小时最多 20 条
- 改完重启桥接

建议先拿自己的测试群试——群聊是举报高发区。

## 八、常见问题

| 现象 | 原因 |
|---|---|
| 状态灯一直「NapCat 未连接」 | NapCat 没起，或 HTTP 服务器端口不是 3000 |
| 灯绿了但发消息没反应 | HTTP **上报**没配，或写成了 `localhost`，改成 `127.0.0.1` |
| 启动后没反应 | `core\logs\` 里当天的日志搜 `[engine]`，多半是 Key 填错或 DSH 路径没找到 |
| 只发文字不发语音 | 看日志里的 `[tts]`：依赖已在 `_vendor\`，多半是网络连不上微软语音接口 |
| 提醒到点没响 | 确认桥接进程在跑；`/提醒` 能看到条目才算存进去了 |
| 群里 @ 了不回 | `group.enabled` 没开，或群号不在 `allowed_groups` |
| 回复很慢 | 会话太长，`session_rotate.max_turns` 调小到 15 |
| 检查更新提示没配地址 | 在 `config.json` 加 `"update": {"url": "https://.../version.json"}` |
